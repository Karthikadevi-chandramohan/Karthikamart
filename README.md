# KarthikaMart 🛒

KarthikaMart is a multi-vendor e-commerce web application developed using Java, Servlets, Maven, and the H2 database.

## Features

* User Registration and Login
* Product Listing
* Shopping Cart
* Checkout
* My Orders
* Seller Orders
* Admin Dashboard
* Product Management

## Technologies Used

* Java
* Java Servlets
* Apache Maven
* H2 Database
* Apache Tomcat 9
* HTML, CSS, and JavaScript

## Project Structure

* `src/main/java/` — Java source code
* `src/main/resources/` — Database schema and resources
* `webapp/` — Web pages and application interface
* `pom.xml` — Maven configuration
* `Dockerfile` — Docker deployment configuration

## How to Run

1. Install JDK, Apache Maven, and Apache Tomcat 9.
2. Clone this repository.
3. Build the project using Maven.
4. Deploy the generated WAR file to Tomcat 9.
5. Start Tomcat and open the application in your browser.
