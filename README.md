# KarthikaMart 🛒

KarthikaMart is a multi-vendor e-commerce web application developed using Java Servlets, Maven, and the H2 database.

## Features

- User Registration and Login
- Product Listing
- Shopping Cart
- Checkout and Order Placement
- My Orders
- Seller Orders
- Admin Dashboard
- Product Management

## Technologies Used

- Java
- Java Servlets
- Apache Maven
- H2 Database
- Apache Tomcat 9
- HTML, CSS, and JavaScript

## Project Structure

- `src/main/java/` — Java source code
- `src/main/resources/` — Application resources
- `src/main/webapp/` — Web pages and application interface
- `pom.xml` — Maven configuration
- `Dockerfile` — Docker deployment configuration (if included)

## How to Run

1. Install JDK 17, Apache Maven, and Apache Tomcat 9.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Build the project using:

   ```bash
   mvn clean package
   ```

5. Deploy the generated WAR file to Tomcat 9.
6. Start Tomcat and open the application in your browser.
